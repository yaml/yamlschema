Using the YAMLSchema editor

      
    

    

      

        This editor converts between YAMLSchema and JSON Schema so you can
        work in either format and see the equivalent representation beside it.
        It also verifies that the source roundtrips to the other format and
        back without losing information.
        When the schema file doesn't roundtrip, a diff is available to show
        where the information was lost.
      

      

        
Choose a starting schema

        

          The left menu contains YAMLSchema examples and the right menu
          contains JSON Schema examples.
          Choosing either one makes that pane the source and generates the
          other representation.
          The URL changes to a shareable schema link.
        

      

      

        
Edit and convert

        

          Edit YSD in the left pane or JSON Schema in the right pane.
          Conversion happens automatically after you stop typing and runs
          entirely in this browser.
          Generated panes display a short message while conversion is active.
        

        

          Select YSDC to inspect the canonical YAMLSchema representation.
          YSDC is generated and read-only, so switch back to YSD to edit the
          YAMLSchema source.
        

      

      

        
Understand roundtrip status

        
    
          
  • … means the roundtrip is being checked.
    • 
          
  • √ means the supported meaning survived.
    • 
          
  • 
            X means it changed.
            Select the X to inspect a unified diff.
          
    • 
          
  • 
            ? means the source could not be parsed or
            converted.
          
    • 
        

        

          The indicator appears only beside the current source pane.
          Focusing an editable pane also starts a fresh roundtrip check.
        

      

      

        
Normalize JSON Schema

        

          Normalize rewrites the JSON Schema into the converter's canonical
          representation, regenerates YAMLSchema, and runs another roundtrip
          check.
        

      

      

        Edits are not saved.
        Reloading the page restores the packaged schema named by the URL.
